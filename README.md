PREVIEW LOCALLY
1. Extract the ZIP.
2. Double-click index.html to open it in a browser.
3. The background image loads from Unsplash, so an internet connection is needed for that image.

PUBLISH FOR FREE WITH CLOUDFLARE PAGES
1. Visit https://pages.cloudflare.com/ and create/sign in to a free Cloudflare account.
2. In the dashboard, open Workers & Pages (or Pages) and create a Pages project.
3. Choose the direct-upload option if offered.
4. Upload the extracted site folder or upload the ZIP, following the dashboard prompts. If asked for a folder, extract the ZIP first and upload the folder containing index.html.
5. Deploy the site. Cloudflare will provide a free *.pages.dev address.
6. Open the deployed address and test the Discord, PayPal, and copy-address links.

ALTERNATIVE: GITHUB PAGES
1. Create/sign in to https://github.com/
2. Create a PUBLIC repository such as brown-town-dayz.
3. Upload index.html at the top level of the repository.
4. Open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch, select main and /(root), then save.
6. GitHub will show the published site address in Settings > Pages.
